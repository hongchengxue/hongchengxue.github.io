# 语言类型

## Python

由 Guido van Rossum 于 1991 年创建，语法接近自然英语.

在 AI 和数据科学领域占据主导地位.

缺点是运行较慢，但开发速度更快.

## C、C++

C 由 Dennis Ritchie 于 1972 年在贝尔实验室创建，是现代语言的“共同祖先”，几乎没有中间层，直接接近硬件指令，速度极快但需自行管理内存；

Windows、Mac、Linux 内核、汽车、微波炉和火星探测器都依赖它。

C++ 由 Bjarne Stroustrup 于 1983 年创建，在保留 C 速度的同时增加大型复杂软件的组织能力，主导电子游戏开发，虚幻引擎、Chrome 和华尔街交易系统都基于它。

## JavaScript和TypeScript

JavaScript 是“互联网的语言”，1995 年由 Brendan Eich 仅用十天开发，负责网页交互；

名字与 Java 无关，纯属营销蹭热度；缺点是错误静默、大型项目维护困难。

TypeScript 由微软于 2012 年推出，在 JavaScript 之上增加类型系统，像“代码的拼写检查”，能在编写阶段发现错误，现已主导严肃 Web 开发并成为 GitHub 使用最广的语言。

## PHP 以及 HTML/CSS

PHP 是“被调侃最多的语言”，但约 70% 的网站运行在它之上，主要归功于 WordPress；

它位于服务器端，负责登录验证、数据库读取和页面构建。

HTML 负责页面结构（标题、段落、图片、链接），CSS 负责样式（颜色、字体、间距、动画），两者不能做逻辑运算，因此不算真正的编程语言，JavaScript 才是让页面“活起来”的关键。

## Java

1995 年由 James Gosling 团队在 Sun Microsystems 开发，核心承诺是“一次编写，到处运行”，通过 Java 虚拟机实现跨平台；

长期支撑银行系统、航空预订和安卓应用，代码繁琐但结构严格，受大型企业青睐。

## C#

微软于 2000 年回应 Java 而生，比 Java 更简洁易写；

实际上代表四个加号叠加，也有音乐音符致敬的意思；

Unity 引擎让它成为手机游戏和独立游戏的主力语言，全球半数手机游戏出自 Unity。

## Rust、Go

Rust 针对 C/C++ 的内存安全问题而设计，通过“借用检查器”在编译前拦截不安全代码，

连续九年被评为最受喜爱语言，微软和 Linux 内核都在引入，政府也提倡转向 Rust 等安全语言。

Go 由谷歌于 2009 年推出，解决大型项目编译慢和代码风格混乱的问题，刻意只提供一种标准写法，Docker 和 Kubernetes 均用 Go 构建。
